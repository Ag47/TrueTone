

# TrueTone

TrueTone, una aplicación de música integrada práctica y compacta, que establece una nueva norma para compartir tu música sin limitaciones.
 
TrueTone coloca la creación, revisión y compartición completa directamente en tu dispositivo Android, con características asombrosas sin precedentes.
Todo en una sola aplicación que te ofrece una experiencia totalmente nueva.
 
Aunque no estés familiarizado con la música, TrueTone te permite crear un tono de llamada fácilmente. Podrás sentirte cómodo al instante.
Independientemente de si estás conectado a Internet o no, TrueTone te permite compartir tu tono de llamada con un código QR.
 
### Rompiendo límites

Puedes ajustar la velocidad de cada nota inclinando tu teléfono móvil o mediante el sensor de proximidad para reemplazar la acción de martillo del piano, ya que el sensor de presión aún no está desarrollado para móviles actualmente.
 
### Dedicado a la perfección

TrueTone transforma tu móvil en una aplicación de música integrada. El usuario puede crear su tono de llamada original sin ninguna barrera de ubicación mientras usa TrueTone. Transformando tu idea exactamente en un tono de llamada.
 
### Multiplataforma

Ahora el usuario puede acceder a TrueTone no solo desde un dispositivo Android sino también desde un navegador web. TrueTone proporciona una forma sencilla de acceder a tonos de llamada con tus amigos. Escucha los tonos de otros compartidos por personas creativas de todo el mundo.

####Otras características:

- Visualización de partituras

- Servicio de almacenamiento en la nube
